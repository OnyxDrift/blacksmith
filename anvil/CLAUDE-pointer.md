## Anvil

Anvil is long-term memory shared across projects: approved notes on past
decisions, fixes, and facts.

- Before researching or re-deriving something that may already be settled, run `/anvil:recall <keyword>`.
- When a durable lesson, decision, or fact lands, or the user asks to remember something, use `/anvil:note`.
- Reach the vault only through `anvil` commands. They return approved notes and keep drafts out of results.
- When a recalled note changes what you do, say so in one `Anvil:` line: its title and how it applies.
